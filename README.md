# Car Price Predictor

A machine learning web application built with Python and Streamlit to predict used car prices.

## Project Overview
This project uses data science techniques to analyze used car data and deploy an interactive prediction model.

## Skills Used
- **Python & Data Science:** Pandas, Scikit-learn
- **Web Framework:** Streamlit Community Cloud
- **Version Control:** Git & GitHub
